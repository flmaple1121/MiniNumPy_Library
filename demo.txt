    "### 5.1 Application 1: 2D Geometric Transformations\n",
    "\n",
    "We will define a simple shape (the outline of a house), apply scaling, rotation, and shear transformations using matrix multiplication, and visualize the results with `matplotlib`."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "metadata": {},
   "outputs": [],
   "source": [
    "# Define a simple house shape with (x, y) coordinates\n",
    "# We use homogeneous coordinates (x, y, 1) for matrix transformations\n",
    "house_coords = mnp.array([\n",
    "    [0, 0, 1], # Four corners of the house\n",
    "    [0, 1, 1],\n",
    "    [1, 1, 1],\n",
    "    [1, 0, 1],\n",
    "    [0, 0, 1], # Back to origin to close the shape\n",
    "    [0.5, 1.5, 1], # Tip of the roof\n",
    "    [1, 1, 1], # Connect roof\n",
    "    [0, 1, 1]  # Connect roof\n",
    "])\n",
    "\n",
    "# Define a plotting helper function\n",
    "def plot_shape(coords, title):\n",
    "    # Matplotlib and NumPy slicing work best with NumPy arrays.\n",
    "    # So, we convert our list data into a NumPy array just for plotting.\n",
    "    data_to_plot = np.array(coords.data)\n",
    "    # Now we can safely use NumPy-style slicing\n",
    "    plt.plot(data_to_plot[:, 0], data_to_plot[:, 1])\n",
    "    plt.title(title)\n",
    "    plt.xlim(-2, 2)\n",
    "    plt.ylim(-2, 2)\n",
    "    plt.gca().set_aspect('equal', adjustable='box')\n",
    "    plt.grid(True)\n",
    "\n",
    "# --- 1. Define Transformation Matrices ---\n",
    "\n",
    "# Scaling matrix: 1.5x in x-axis, 0.5x in y-axis\n",
    "scale_matrix = mnp.array([\n",
    "    [1.5, 0, 0],\n",
    "    [0, 0.5, 0],\n",
    "    [0, 0, 1]\n",
    "])\n",
    "\n",
    "# Rotation matrix: Rotate counter-clockwise by 45 degrees\n",
    "angle = math.radians(45)\n",
    "c, s = math.cos(angle), math.sin(angle)\n",
    "rotation_matrix = mnp.array([\n",
    "    [c, -s, 0],\n",
    "    [s, c, 0],\n",
    "    [0, 0, 1]\n",
    "])\n",
    "\n",
    "# Shear matrix: Shear along the x-axis\n",
    "shear_matrix = mnp.array([\n",
    "    [1, 0.5, 0],\n",
    "    [0, 1, 0],\n",
    "    [0, 0, 1]\n",
    "])\n",
    "\n",
    "# --- 2. Apply Transformations ---\n",
    "# Note: The transformation matrix should be on the right, so we transpose the coordinate matrix first\n",
    "scaled_house = (house_coords @ scale_matrix.transpose()).transpose()\n",
    "rotated_house = (house_coords @ rotation_matrix.transpose()).transpose()\n",
    "sheared_house = (house_coords @ shear_matrix.transpose()).transpose()\n",
    "\n",
    "# --- 3. Visualize the Results ---\n",
    "plt.figure(figsize=(12, 10))\n",
    "\n",
    "plt.subplot(2, 2, 1)\n",
    "plot_shape(house_coords.transpose(), 'Original House')\n",
    "\n",
    "plt.subplot(2, 2, 2)\n",
    "plot_shape(scaled_house, 'Scaled House')\n",
    "\n",
    "plt.subplot(2, 2, 3)\n",
    "plot_shape(rotated_house, 'Rotated House (45 deg)')\n",
    "\n",
    "plt.subplot(2, 2, 4)\n",
    "plot_shape(sheared_house, 'Sheared House')\n",
    "\n",
    "plt.show()"
   ]

    "### 5.2 Application 2: Simple Image Processing\n",
    "\n",
    "We will create a simple 8x8 grayscale image (represented by a `mininumpy` matrix) and perform two basic operations on it: brightness enhancement and color inversion."
   ]

  {
   "cell_type": "code",
   "execution_count": null,
   "metadata": {},
   "outputs": [],
   "source": [
    "# Create an 8x8 grayscale image (0=black, 255=white)\n",
    "image = mnp.zeros((8, 8))\n",
    "# Draw a bright cross on the image\n",
    "image.data[3][:] = [180] * 8\n",
    "for i in range(8):\n",
    "    image.data[i][3] = 180\n",
    "\n",
    "# --- 1. Increase Brightness ---\n",
    "# Achieved by adding a constant value to every pixel\n",
    "brighter_image = image + 50\n",
    "# Note: In a real application, pixel values > 255 would need to be clipped.\n",
    "# This is simplified for demonstration purposes.\n",
    "\n",
    "# --- 2. Invert Colors ---\n",
    "# Achieved by subtracting the current pixel value from the maximum value\n",
    "max_pixel_value = 255\n",
    "inverted_image = max_pixel_value - image\n",
    "\n",
    "# --- 3. Visualize the Results ---\n",
    "plt.figure(figsize=(15, 5))\n",
    "\n",
    "plt.subplot(1, 3, 1)\n",
    "plt.imshow(image.data, cmap='gray', vmin=0, vmax=255)\n",
    "plt.title('Original Image')\n",
    "\n",
    "plt.subplot(1, 3, 2)\n",
    "plt.imshow(brighter_image.data, cmap='gray', vmin=0, vmax=255)\n",
    "plt.title('Brighter Image')\n",
    "\n",
    "plt.subplot(1, 3, 3)\n",
    "plt.imshow(inverted_image.data, cmap='gray', vmin=0, vmax=255)\n",
    "plt.title('Inverted Image')\n",

    "## 6. Conclusion\n",
    "\n",
    "This demonstration shows that the `mininumpy` library successfully replicates a core subset of NumPy's functionality.\n",
    "\n",
    "* **Correctness**: For all tested basic and linear algebra operations, `mininumpy`'s results are consistent with NumPy's (within floating-point precision limits).\n",
    "* **Practicality**: The library is robust enough to support interesting practical applications, such as 2D transformations and basic image pixel manipulation, proving the effectiveness of its design.\n",
    "\n",
    "Of course, there is a significant gap between `mininumpy` and `numpy`, primarily in:\n",
    "* **Performance**: `mininumpy` is based on pure Python lists, whereas NumPy's backend is implemented in C and Fortran, making it orders of magnitude faster.\n",
    "* **Feature Breadth**: `mininumpy` lacks advanced indexing, a full broadcasting mechanism, support for multiple data types (dtypes), and many other advanced features.\n",
    "\n",
    "Overall, this project is a successful exercise that provides a deep understanding of the underlying principles and API design of a numerical computing library."
