\doxysubsection{Detailed Description}
A simplified multi-\/dimensional array class, similar to Num\+Py\textquotesingle{}s ndarray. 

This class wraps a Python list (or nested lists) and provides methods for basic array manipulation, such as shape, transpose, and elementwise operations.
