Detailed Description

MiniNumPy Linear Algebra Module.

Contains functions for linear algebra operations like dot product, matrix multiplication, determinant, and inverse.

◆ det()

mininumpy.linalg.det ( a)

Calculates the determinant of a square 2D array.

This implementation uses recursive Laplace expansion. It is not efficient for large matrices but is simple to implement.

Parameters
aA square 2D Array.
Returns
The determinant of the array. @raises ValueError if the array is not square or not 2D.

◆ inv()

mininumpy.linalg.inv ( a)

Calculates the inverse of a square 2D array.

The inverse is calculated using the formula: inv(A) = (1/det(A)) * adj(A), where adj(A) is the adjugate matrix (transpose of the cofactor matrix).

Parameters
aA square, invertible 2D Array.
Returns
The inverse of the array. @raises ValueError if the array is not square or is singular (det=0).
